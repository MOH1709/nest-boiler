## Description

- Nest JS Boiler plate for your project to maintain a large scale project

## Technologies

- Nest JS
- Prisma
- Postgres
- Eslint
- Prettier
- Husky
- Jest
- Swagger

### Requirement

- Node v20
- Postgres

### Installation

```bash
$ npm install
```

### Running the app

```bash
$ npm run prisma:generate
$ npm run db:deploy
$ npm run dev
```

### Adding Data in Database If Required

```bash
$ npm run db:seed
```

### Test

```bash
$ npm run test
```
